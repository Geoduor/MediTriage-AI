                         MEDI TRIAGE AI - PROJECT STRUCTURE
================================================================================

PROJECT TITLE
=============
MediTriage AI: Smart Healthcare Triage for Kenya's Primary Care Network

ONE-LINE SUMMARY
================
AI reads patient symptoms → instantly tells health workers if it's RED/YELLOW/GREEN

PROBLEM → SOLUTION
==================
❌ Clinics overwhelmed, triage by gut feel, urgent cases missed
✅ AI triages in 30 seconds, color-coded urgency, tells where to go + cost

================================================================================
                              TECH STACK SUMMARY
================================================================================

FRONTEND
  - Framework: Next.js (React)
  - Language: JavaScript/JSX
  - Styling: CSS
  - Deployment: Vercel
  - Features: Mobile-first, printable

BACKEND
  - Framework: FastAPI (Python)
  - Language: Python 3.9+
  - Deployment: Render
  - Key Libraries: anthropic, uvicorn, pydantic

AI/ML
  - LLM: Claude (Anthropic API)
  - Embeddings: NVIDIA Brev
  - Models: claude-opus-5.5

DATABASE
  - Format: JSON files (MVP)
  - Conditions: conditions.json
  - Rules: triage_rules.json
  - Tests: test_cases.json
